# Machine Learning Lab Experiments

This repository contains my Machine Learning laboratory experiments implemented using Python and Jupyter Notebook.

## 📂 Files

- `86_ml lab_exp1.ipynb` – Machine Learning Experiment 1 (Classification using the Iris Dataset)
- `86_ml lab_exp2.ipynb` – Machine Learning Experiment 2 (Spam Email Classification using Support Vector Machine)

## 🛠️ Technologies Used

- Python
- Jupyter Notebook
- NumPy
- Pandas
- Matplotlib
- Scikit-learn

## 📊 Datasets

- Iris Dataset
- Spam Email Dataset

## 🎯 Objectives

- Perform data preprocessing and visualization.
- Train Machine Learning models.
- Evaluate model performance using appropriate metrics.
- Understand real-world classification problems.

## ▶️ How to Run

1. Clone this repository.
2. Open the notebooks in Jupyter Notebook or Google Colab.
3. Install the required Python libraries.
4. Run all cells in sequence.
